Virtual machines on {{.Agent.Name}}

A running VM is switched onto temporary overlay files while its disks are read, so the disk images hold still, then everything is merged back. With the QEMU guest agent installed and "freeze" ticked, guest filesystems are flushed and frozen for the instant the overlay is created; otherwise the copy is crash-consistent (like pulling the power). A shut-off VM is copied as is. Only writable file-backed disks can be backed up; CD-ROMs and block devices are listed but skipped.
